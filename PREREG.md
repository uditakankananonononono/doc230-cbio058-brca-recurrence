# CBIO058 "Deep-Learning to Predict Breast Cancer Recurrence" (2023, Ariana Rahman) - preregistration
Written and committed WITH src/run058.py before any outcome is scored. In the commit chain this precedes every results commit (commit dates are author-set, not independently timestamped).

Disclosure: before this commit I ran src/run058.py with SMOKE=1 (400 random patients, RANDOM-PERMUTED labels, 1 epoch, outputs to /tmp) purely as a crash test; no real-label outcome was scored or viewed, and the only edits after it were memory (streaming file reader) and that smoke hook.

## What the abstract claims, and what this can test
Multi-omics (gene expression + copy number) integrated by a modified autoencoder "AIME" that adjusts for a confounder (estrogen receptor, ER, status); the integrated embedding goes to a Random Forest to separate "disease free" from "recurred" samples; a list of the 25 most significant genes is reported as biomarkers. The abstract names no dataset and gives no accuracy number in the text available to me. The student's data, code and the real AIME code are not available.
We test: on a public cohort with expression, copy number and recurrence status, (a) does an AIME-STYLE confounder-conditioned cross-modal autoencoder + RF predict recurrence, (b) is that better than plain baselines, (c) is it explained by ER, treatment, follow-up length, cohort or leakage, (d) is a "25 genes" list specific and stable. LIMITS: this is my reimplementation of the idea from the abstract's description (not the authors' AIME); a different cohort from the student's; one public cohort; the 25-gene claim is tested only in the form defined in D9.

## Data (fixed before scoring)
METABRIC (Curtis 2012 / Pereira 2016) as distributed by cBioPortal datahub: https://datahub.assets.cbioportal.org/brca_metabric.tar.gz (sha256 in data_manifest.txt). Files: data_clinical_patient.txt, data_clinical_sample.txt, data_mrna_illumina_microarray_zscores_ref_diploid_samples.txt (Illumina HT-12 expression, z-scored against diploid samples), data_cna.txt (discrete copy number).
Cohort: patients with RFS_STATUS in {0:Not Recurred, 1:Recurred}, with expression AND copy number AND known ER status (sample-file ER_STATUS Positive/Negative). Label y = 1 recurred. Known problems stated up front: (1) "Not Recurred" is right-censored: many have short follow-up, so they are not truly disease-free (D5 checks); (2) ER status and treatment strongly relate to recurrence (D4, D6); (3) METABRIC pools several cohorts (COHORT 1-9; D8); (4) recurrence timing differs, no time-to-event model is fit.

## Pipeline (fixed)
Stratified 5-fold CV, seed 0, single run. Within each TRAINING fold only: keep the 2,000 expression genes and 2,000 copy-number genes of highest variance; fit the AIME-style model; embed train and test with it. AIME-style model (never sees y): two encoders (expression 2000->256->32, CNA 2000->256->32, ReLU), shared embedding z = mean of the two encoder outputs, decoders take [z, c] (c = ER status, 0/1) and reconstruct both modalities (so z need not carry ER), loss = MSE(expr)+MSE(CNA)+0.1*MSE(z_expr, z_cna), Adam lr 1e-3, weight decay 1e-4, 60 epochs, batch 128, torch seed 0, CPU. Classifier: RandomForest 300 trees, max_features sqrt, seed 0, n_jobs 2, on the 32-d embedding. Metric: AUROC (primary) and accuracy, mean over folds with sample sd (ddof=1); bootstrap 95% CI (2000 resamples, seed 0) over pooled out-of-fold predictions for the headline.

## The 10 directions (all run; gates fixed now, not re-fitted after a miss)
D1 Data audit: counts, ER and cohort breakdown, follow-up of non-recurred, missingness. No gate.
D2 Headline: pipeline above. Gate "predicts recurrence": pooled out-of-fold AUROC >= 0.70.
D3 Baselines: (a) RF on the raw top-2000 expression + top-2000 CNA features (no autoencoder); (b) RF on clinical-only variables (age, positive lymph nodes, tumor size, stage, grade, ER, HER2, PR, NPI; median/mode imputation inside fold). Gate "AIME adds value": D2 AUROC minus the better baseline >= 0.02.
D4 ER confound: (a) ER status alone as the only feature; (b) D2 without the confounder input (decoders get z only); (c) D2 run separately within ER+ and within ER- (5-fold inside each stratum). Gates: "ER confound material" if (a) AUROC >= 0.55; "adjustment matters" if |D2 AUROC - (b) AUROC| >= 0.02. Report (c) AUROCs.
D5 Label validity: drop Not-Recurred patients with RFS_MONTHS < 60 (keep all Recurred); rerun D2 and the clinical baseline; also the AUROC of follow-up length alone (a post-outcome variable, shown only to expose label structure, never a feature). Gate "censoring-sensitive": |AUROC change| >= 0.05.
D6 Treatment confound: (a) chemotherapy, hormone therapy, radiotherapy and surgery type as the only features; (b) D2 within hormone-therapy YES and NO strata. Gate "treatment confound material": (a) AUROC >= 0.55.
D7 Leakage control: variance filter and autoencoder fitted on ALL samples (labels still unused) before CV, vs training-fold-only. Gate "leakage matters": AUROC higher by >= 0.02.
D8 Cohort/batch: (a) 5-fold accuracy of predicting COHORT from the embedding vs majority-class baseline; (b) leave-one-cohort-out recurrence AUROC over cohorts with >= 100 patients, mean. Gate "cohort-dependent": LOCO mean AUROC < D2 AUROC - 0.05.
D9 Null and biomarker list: (a) full-pipeline permutation: labels permuted (5 permutations, seed 0), whole CV rerun with the autoencoder refit per fold; sane if mean AUROC within 0.50 +/- 0.03. (b) "Top-25 genes": within each training fold, gene score = sum over the 32 dimensions of (RF importance_k x |corr(gene expression, z_k)|) on the 2,000 selected expression genes; top 25 per fold; held-out AUROC of an RF on only those 25 genes vs 25 random genes from the same 2,000 (10 draws); mean pairwise Jaccard of the 5 folds' lists. Gates: "list specific" if top-25 AUROC exceeds the random mean by >= 0.05; "list stable" if mean Jaccard >= 0.30.
D10 Modality ablation (descriptive): AIME-style model with expression only and with CNA only (same pipeline), AUROC each.

## Wording rule
The README first line states whether D2 passed and which of D3-D9 fired. If D2 passes but ER/treatment/censoring/cohort controls fire, the claim is "predictive in this cohort, not shown to be recurrence biology beyond ER/treatment/follow-up/cohort effects". Any claim that the 25 genes are biomarkers requires "list specific" and "list stable" and a stated external-validation gap (none attempted). Nothing about the student's own model, data or numbers.
